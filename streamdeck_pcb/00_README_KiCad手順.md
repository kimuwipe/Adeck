# 自作StreamDeck PCB 設計ファイル一式

## ※ KiCad 7.x 対応版

このシンボルライブラリは KiCad 7.x 形式（version 20211014）で作成しています。
KiCad 8/9でも読み込めますが、7.x向けに最適化しています。

### インポート手順（KiCad 7）
1. シンボルエディターを開く
2. 「ファイル」→「ライブラリをインポート」
   または「設定」→「シンボルライブラリを管理」→「既存のライブラリを追加」
3. `streamdeck_symbols.kicad_sym` を選択
4. グローバル or プロジェクト固有を選んで追加

| 00_README_KiCad手順.md | このファイル（使い方） |

## KiCadシンボルの取り込み方

1. KiCadを起動 → プロジェクトを開く
2. 「シンボルエディター」を開く
3. メニュー「ファイル」→「ライブラリをインポート」
   または「設定」→「シンボルライブラリを管理」
4. `streamdeck_symbols.kicad_sym` を追加
5. 以下5つのシンボルが使えるようになります：
   - RaspberryPi_Pico2
   - MCP23017
   - Waveshare_1.9_TouchLCD
   - RotaryEncoder_EC11_SW
   - USB_TypeC_5077CR

## 設計の進め方（推奨手順）

1. **回路図（Schematic）作成**
   - 上記シンボルを配置
   - 01_netlist_connection.md の接続表通りに配線
   - 抵抗・コンデンサは標準ライブラリ（Device）から配置

2. **フットプリント割り当て**
   - Pico 2：ピンソケット2×20（着脱式推奨）またはスルーホール
   - MCP23017：DIP-28 or SOIC-28
   - 抵抗・コンデンサ：0805（SMD）or スルーホール
   - LCD/エンコーダ/USB-C：メーカー提供 or 実測でフットプリント作成

3. **PCBレイアウト**
   - GNDベタ（グランドプレーン）を必ず入れる
     ※ブレッドボードのちらつき対策。最重要。
   - 各IC電源ピン近くに0.1μF配置
   - SPI配線（GP18/19）は短く、他信号と離す

## 重要な設計ポイント（実機デバッグで判明）

1. **GNDベタ必須**：ブレッドボードのGND接触抵抗20Ωが表示ちらつきの原因だった。PCBでは太いGNDプレーンで解決する。

2. **バックライトは負論理**：GP26/27がLOWで点灯。ハード的には通常配線でOK（ソフトで対応済み）。

3. **LCD①②のRST共有**：GP21を2画面で共有。ソフト側で初期化順を対応済みなので、ハードは共通配線でOK。

4. **I2Cは2バス**：タッチ①=I2C0（GP4/5、MCPと共有）、タッチ②=I2C1（GP6/7）。プルアップ4.7kΩを各バスに。

5. **USB-C給電**：まずは「給電のみ」パターン推奨（VBUS/GNDのみ接続）。Pico本体USBでデータ通信。詳細は01_netlist参照。

## フットプリントについての注意

このシンボルライブラリには**フットプリント（実物の寸法）は含まれていません**。理由：
- 標準部品（抵抗・コンデンサ・DIP IC）はKiCad標準ライブラリで足ります
- LCD・USB-C・エンコーダはメーカー提供フットプリント、または現物実測での作成が確実です

秋月・Waveshareの製品ページや、SnapEDA等でフットプリントを入手すると効率的です。
