## スイッチ配線（プルアップ方式）

各スイッチSW1〜8：
- 片側 → MCP23017 GPAx
- 各GPAx → 10kΩ → 3V3（プルアップ）
- もう片側 → GND
- 並列に0.1μF（チャタリング対策・任意）

## エンコーダ配線（EC11）

各エンコーダ ENC1〜4：
- A相 → Pico GPx（A）、10kΩで3V3プルアップ
- B相 → Pico GPx（B）、10kΩで3V3プルアップ
- C（コモン）→ GND
- プッシュSW片側 → MCP23017 GPBx、10kΩで3V3プルアップ
- プッシュSW他側 → GND
- A/B各相に0.1μF（GND間、チャタリング対策）

## I2Cプルアップ

| 抵抗 | 接続 |
|------|------|
| 4.7kΩ | GP4 (SDA) ↔ 3V3 |
| 4.7kΩ | GP5 (SCL) ↔ 3V3 |
| 4.7kΩ | GP6 (SDA) ↔ 3V3 |
| 4.7kΩ | GP7 (SCL) ↔ 3V3 |

**【設計メモ】Waveshare 1.9inch Touch LCDは内部にプルアップ内蔵**
公式回路図より、モジュール内部でタッチI2C（TP_SDA/TP_SCL）に10kΩプルアップが実装されている。
そのため、メイン基板側の4.7kΩと合わせると合成 10k∥4.7k ≈ 3.2kΩ となる（二重付け）。
これは意図的に許容している：
- 合成3.2kΩはI2C許容範囲（1k〜10k）内で、400kHz動作に支障なし
- LCDを外してMCP23017単体でデバッグする際、メイン側プルアップが機能する冗長性を確保
厳密に最適化するならメイン側タッチ系プルアップを省略可能だが、上記理由で現状維持とする。

## USB-C コネクタ（AE-USB2.0-TYPE-C-5077CR / 秋月115426）

秋月のType-C DIP化キット。7ピン引き出し（VBUS、GND×2、D+、D-、CC1、CC2）。
**USB2.0デバイスとして使うため、CC1/CC2を各5.1kΩでGNDへプルダウンが必須。**

| USB-Cピン | ネット | 接続先 | 備考 |
|-----------|--------|--------|------|
| VBUS | VBUS | Pico 40番(VBUS) | 5V入力 |
| GND | GND | Pico GND | グランド（2本ともGNDへ） |
| D+ | USB_DP | Pico USB D+ | データ+（※下記注意） |
| D- | USB_DM | Pico USB D- | データ−（※下記注意） |

| CC2 | CC2 | 5.1kΩ → GND | プルダウン必須 |

### USB-C使用時の重要な注意

**Pico 2は基板上に既にUSB-Cコネクタを搭載しています。** そのため、外部USB-Cをどう使うかで配線が変わります。

**パターンA：外部USB-Cから給電のみ（推奨・簡単）**
- VBUS → Pico VBUS(40番)、GND → Pico GND のみ接続
- D+/D-、CC1/CC2は未接続でOK（データはPico本体のUSBを使う）
- 外部USB-Cは「電源入力専用」になる

**パターンB：外部USB-Cでデータ通信もする（上級・非推奨）**
- Pico 2のUSB D+/D-テストポイントへの配線が必要（基板裏の小さいパッド）
- Pico本体のUSBと排他利用。配線が難しく、初回はパターンA推奨
- CC1/CC2の5.1kΩプルダウンが必要

**まずはパターンA（給電のみ）を強く推奨します。** Pico本体のUSB-Cでファーム書き込み・データ通信し、外部USB-Cは電源供給用と割り切るのが確実です。その場合、外部USB-CのD+/D-/CC配線とプルダウン抵抗も不要になります（電源2本だけ）。

## 重要な設計メモ

1. **GNDは太く・多点接続**：ブレッドボードでのちらつきはGND接触抵抗が原因だったため、PCBではGNDプレーン（ベタGND）を強く推奨。
2. **バックライトは負論理**：GPxがLOWで点灯。ソフト側で対応済み。
3. **RST共有**：LCD①②でRST(GP21)共通。ソフト側で初期化順を対応済み。
4. **デカップリング**：各IC電源ピン近傍に0.1μFを配置。VBUS-GND間に10μF。

5. **3V3バルクコンデンサ（C5, 100μF）**：Pico 3V3(OUT)ピン近傍に配置。2枚のLCD同時起動時の突入電流による電圧ドロップを吸収する保険。0.1μF（高周波用）とは役割が異なるため別に配置する。
   - 消費電流の実測見積り：3V3側 合計約120mA（LCD BL×2で約60mA支配的）＋Pico本体 40〜100mA＝総負荷 約160〜220mA。Pico 2オンボード3V3レギュレータの安全圏（300〜400mA）内で余裕あり。
